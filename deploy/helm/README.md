# Helm Assets

Lifecycle: **ACTIVE PLACEHOLDER**

`bitcoin-bastion/` contains chart metadata and a values contract, but no
`templates/` directory. It is not an installable deployment method. Keep Helm
assets here so all non-conventional deployment material has one owner under
`deploy/`.

See [`docs/DEPLOYMENT_METHODS.md`](../../docs/DEPLOYMENT_METHODS.md) for the
supported deployment methods and their verification requirements.
