# Feature Catalog

Feature catalog is exposed by `GET /api/v1/public/features` and includes Trace/Citadel/Treasury/Register/Observability-oriented entries in baseline form.

## Access Layer feature catalog alignment

Proof-of-Access is the protected-API auth model. Live capabilities include payment intents, certificate issuance, origin-bound challenges, PoP sessions, Access `/me` metadata, entitlement/limit views, recovery setup/attempts, child API keys, delegated passes, human-intent manifests, lockdown, revocation, and audit events. Offline validity packs and PQ algorithms remain planned/reserved unless separately implemented and tested.
