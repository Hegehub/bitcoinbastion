# Bastion Trace Limitations

- Deterministic baseline scoring weights are not production-calibrated.
- No legal/compliance verdicts are produced.
- No Bitcoin consensus proof is produced.
- External source trust/calibration is not production-validated by default.
- Full transaction-graph intelligence is not implemented.
- ML-driven risk inference is not implemented.
- Privacy shield components are heuristic and source-limited.
- UTXO hygiene output depends on available evidence.
- Toxic change is a heuristic signal.
- Provider disagreement is advisory and affects confidence context.
- Enterprise RBAC/SSO/SIEM are placeholders unless fully integrated/configured.
- Proof packets are evidence bundles, not legal certificates.
- No transaction signing or broadcasting occurs.
- No custody, seed phrase, or private key handling is supported.

- Replay determinism depends on preserved evidence snapshots and canonical serialization inputs.
- Production deployment still requires auth/rate limiting/observability validation evidence.
