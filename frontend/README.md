# Frontend

This directory contains the UI implementations for Bitcoin Bastion. The `reflex` subdirectory is intended to house the current Reflex-based web interface. The `telegram` subdirectory is reserved for future Telegram UI work.

- `reflex/`: The Reflex Python-first frontend (see the `reflex_frontend` directory at the repository root for the full implementation). Once the migration is complete, its contents should be moved here.
- `telegram/`: Placeholder for a future Telegram client. Components and bots will be added here.
