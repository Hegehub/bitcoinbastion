# Reflex i18n Foundation

## Supported languages

- English (`en`)
- Russian (`ru`)

## Translation key structure

Keys use dotted namespaces for navigation, safety, Trace, Evidence, Console, degraded states, and errors.

## Fallback behavior

Unsupported languages fall back to English. Missing keys return the key string instead of crashing.

## How to add a language

Add the language code to `SUPPORTED_LANGUAGES`, add a translation dictionary in `translations.py`, and ensure all safety keys are translated without softening warnings.

## Safety copy translation rules

Safety warnings must remain direct and conservative. Do not soften no-custody, sensitive-material, degraded-state, not-legal-verification, not-consensus-proof, or not-financial-advice copy.
